# 卡牌資料庫

## 結構

```
card-database/
├── src/
│   ├── types.ts      卡牌紀錄的格式
│   ├── official.ts   把官方卡表資料轉成引擎用的印刷資料（不認得的欄位一律報錯）
│   ├── decks.ts      測試卡組及 Neo-Standard 禁卡（目前只抄錄了與資料庫有關的項目）
│   └── index.ts      載入所有系列
├── sets/<系列>/
│   ├── official.json 官方卡表資料，原樣保存，附來源、取得日期及雜湊值
│   └── cards.ts      人手編寫的部分：能力資料、繁中解釋、支援狀態、備註
└── tests/            每張卡的測試、資料完整性測試、用真實卡組打完整對局
```

### 為甚麼能力資料寫在 `.ts` 而不是 `.json`

技術架構原本寫卡牌資料用 JSON。實作時把**能力資料**改放在 TypeScript 檔案，原因是型別檢查：能力格式（`game-engine/src/abilities/types.ts`）有數十種構件，寫在 `.ts` 內任何拼錯或缺漏都會在編譯時被發現；寫在 JSON 則要另寫一套執行期驗證器才有同樣保障。能力仍然是純資料，引擎沒有任何為個別卡牌寫的程式碼。官方印刷資料仍然是 JSON。

## 規則

- **印刷資料不人手輸入**：卡名、Level、Cost、Power、Soul、特徵、Trigger 圖示、顏色全部由 `official.json` 轉換。轉換器遇到未核實的圖示（例如還沒有在任何卡的提示文字確認過意思的 Trigger 圖示）會報錯，不會猜。
- **官方原文與解釋分開**：原文只在 `official.json`；繁中解釋在 `cards.ts`，一律標示 `AI_ASSISTED`（AI 輔助說明）及「待核實」。
- **支援狀態**：`verified`（已對照官方原文、エラッタ及 Q&A，並有通過的測試）、`pending`（只限測試模式）、`unsupported`（未確認 — 暫不支援自動執行，不能用於對戰）。測試會檢查每張 `verified` 的卡都有測試，以及測試卡組只用 `verified` 的卡。
- **卡圖**：不下載、不保存任何官方卡圖。`official.json` 只記錄官方圖片的路徑。

### SAO 及 GUP 為甚麼只收錄部分卡

只選了引擎可以按官方原文準確執行的卡，而且盡量選效果不同的卡（CX Combo、搜尋山札、回收、絆、チェンジ、助太刀、Counter Event、集中、給予 Encore、離開舞台時的能力，以及 Shot、Draw、Treasure、Choice、Gate 五種新 Trigger 圖示）。沒有選的卡多數需要引擎尚未支援的內容，例如：

- 「直至對手下一回合結束」的效果、Marker 及搭乗、在思い出生效的能力；
- 「對手不能使用 Encore／Event／助太刀」、每次攻擊進行兩次 Trigger Check；
- 按對手角色數目或某角色的 Soul 計算的數值、「二選一」效果、「最多抽 2 張」。

這些卡沒有收錄，而不是以簡化效果收錄。GUP 系列選擇的原因見 `docs/04-visual-card-expansion-plan.md` 第 6 節。

長時間測試會列出測試卡組中從未被使用的能力；目前只有 GUP/W141-099 的第三個能力，因為它需要的「BT-42のなんでも屋 アキ」未收錄（卡上已註明）。

為這兩個系列，引擎加入了兩個小構件（都有卡牌測試）：「我方 Trigger 圖示是某種的 Climax 放到 Climax 置場時」及「Climax 置場有任何 Climax 時」。

## 測試卡組

`decks.ts` 有四副本專案自行組成的合法 Neo-Standard 卡組（50 張、同名最多 4 張、Climax 8 張、單一作品），**都不是官方的固定配置或比賽卡組**：涼宮ハルヒ、一花（兩個 Trial Deck 商品頁都沒有公開每種卡的張數）、SAO（黃藍）、GUP（黃綠藍）。涼宮ハルヒ卡組沒有放入禁卡情報連結解除。自動對局測試會輪流使用四副卡組的所有配對。

## 新增一個系列的步驟

1. 在官方卡表以每秒不多於一次的頻率讀取資料，原樣存成 `sets/<系列>/official.json`，記錄來源、日期及雜湊值。
2. 查エラッタ頁及限制表。
3. 逐張對照原文及 Q&A 編寫 `cards.ts`。寫不出來的卡標為 `unsupported` 並寫明原因，不可近似。
4. 為每張 `verified` 的卡寫測試，測試名稱要包含卡號。
5. 在 `src/index.ts` 的 `SETS` 加入該系列。
