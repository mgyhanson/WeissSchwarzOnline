# STEP 6b 第二批：SAO 卡池擴充（経験、記憶、アラーム、次の相手のターンの終わりまで）

分支：`feat/card-pool-2`（由 `feat/card-visual-reveal-ux` 開出）。日期：2026-11-12。

## 1. 目標

- 引擎加入「次の相手のターンの終わりまで」的期限，以及需要的新 Cost 和觸發條件；每項都有引擎測試。
- 加入使用這些內容的真實卡，以及使用経験（Experience）、記憶（Memory）、アラーム（Alarm）的卡。
- 卡池達到 100 張以上，而且每張都按官方原文準確執行並有測試；不以簡化效果收錄。

## 3. 引擎新增的構件（`game-engine/src/abilities/types.ts`）

- `MODIFY` 及 `GRANT` 的 `until: 'NEXT_OPPONENT_TURN'`。
- Cost：`REST_CHARACTERS`（把我方（其他）站立中的角色 N 張 Rest，由玩家選擇；新的選擇提示 `COST_REST`）、`STOCK_TO_CLOCK`（Stock 頂 N 張放到 Clock）、`SELF_TO_MEMORY`（這張卡放到思い出）。
- 觸發 `REVERSED` 的 `inBattle`（「バトル中のこのカードが【リバース】した時」）。
- 條件 `LAST_MOVED`（「それらのカードに…があるなら」：同一個效果中剛由山札頂移動的卡）。
- 卡牌條件 `nameIncludesAny`（「カード名に『A』か『B』か『C』を含む」）。
- AI：`COST_REST` 時選最便宜的角色（與棄牌 Cost 相同）。

引擎測試：`game-engine/tests/durations.test.ts`（T-DUR-001 至 003，以及 Cost、`LAST_MOVED`、`inBattle` 的測試）。

## 5. 測試卡組

新增第五副卡組 `test-sao-memory`（ソードアート・オンライン 経験・記憶・アラーム 測試卡組，黃藍，少量綠色 Level 0），由本專案自行組成，不是官方或比賽卡組。自動對局測試輪流使用五副卡組的 20 種配對；AI 測試加入「每副卡組由 AI 打完整局」的檢查。

## 6. 結果

- `npm run check`：448 個測試通過、8 個慢速測試按設計略過；型別檢查及規則覆蓋檢查通過。
- 卡牌測試：`card-database/tests/cards-sao-2.test.ts` 逐張測試，包括「次の相手のターンの終わりまで」在對手回合仍然有效、在之後的我方回合已消失。
- `npm run soak`：4000 局全部通過；真實卡組部分輪流使用五副卡組的 20 種配對。第二批每張卡的每個自動及起動能力都至少被使用過一次；唯一從未被使用的能力仍是 GUP/W141-099 的第三個能力（需要未收錄的「BT-42のなんでも屋 アキ」）。
- `npm run qa:ui`（新增 `QA_DECKS` 選項；這次用 `QA_DECKS=test-sao-memory,test-sao`）：電腦 1366×850、手機直向 375×812、手機橫向 812×375 都是 60 fps，沒有橫向捲動，沒有 Console 錯誤；以新卡組在瀏覽器打完一整局，沒有錯誤。截圖確認新卡（包括 Gate 圖示的 Climax）正常顯示。
