## 2. 規則基準的決定（需要你確認）

**建議：以日文版 ver. 1.114 為引擎唯一規則基準。**

理由：

1. 日文版是最新版本（今天剛更新），英文版落後約 14 個月。
2. 卡牌資料庫以日文官方卡表為來源，卡牌原文是日文。
3. 英文版 v2.10 沒有以下日文版已有的內容：チャンス／ディスカバリー／フォーカス三種 Trigger 圖示、「～まで」「好きな回数」的處理定義（4.10、4.11）、回想、搭乗、ゲーム1 圖示、發生源更新、エンドフェイズ自動能力的明確化。

## 3. 規則重點摘要（按官方章節）

以下只列出**對實作有決定性影響**的內容，括號內為條文編號。

### 3.1 勝負（1.2、9.4）

- 敗北條件有兩個：Level 置場有 4 張或以上；山札和控え室同時沒有任何卡。
- 敗北**不是即時**判定，而是在下一次規則處理（Check Timing）時判定（1.2.2、9.4.1，屬「檢查型」規則處理）。
- 雙方同時敗北 → 平手（1.2.3）。
- 例外是即時的：投降（1.2.4）、卡牌效果指定勝負（1.2.5）、以及 9.2.2.1 的傷害處理中無牌可補。
- 卡牌文字與綜合規則矛盾時，卡牌文字優先（1.3.1）；「禁止」效果永遠優先於「指示」效果（1.3.3）。
- 被要求做不可能的事 → 不做；只有部分可行 → 盡量做（1.3.2）。

### 3.2 區域（第 3 章）

官方定義的區域比你列的 10 個多 **2 個**：

| 區域 | 公開性 | 要點 |
|---|---|---|
| 山札 | 非公開 | 不可看、不可改順序 |
| 手札 | 非公開（自己可看） | 上限 7 張，只在 End Phase 檢查 |
| 控え室 | 公開 | 自己可自由排序 |
| 舞台 | 公開 | 包含 5 個「枠」 |
| **枠**（5 個） | 公開 | 前列 左／中央／右，後列 左／右；有明確的「前後」及「正面」關係（3.6.5、3.6.6） |
| **マーカー置場**（5 個，與枠一一對應） | 非公開（可因效果表向） | 獨立區域，不屬於舞台；角色離開時 Marker 一同處理（3.7.3） |
| クロック置場 | 公開 | 不可改順序，新卡放最上 |
| レベル置場 | 公開（可有裏向卡） | 不可改順序 |
| ストック置場 | 非公開 | 連自己也不可看；只能由最上面取走 |
| クライマックス置場 | 公開 | 原則上只有 1 張 |
| 思い出置場 | 公開（可有裏向卡） | 裏向卡視為沒有任何資訊的空白卡 |
| 解決領域 | 公開 | Event、Trigger Check、傷害、集中 的暫存區 |

前後關係（3.6.5）：後列左 ↔ 前列左、前列中央；後列右 ↔ 前列中央、前列右。
正面關係（3.6.6）：自己前列左 ↔ 對手前列右；中央 ↔ 中央；自己前列右 ↔ 對手前列左。

除了由一個枠移到另一個枠之外，卡牌每次轉換區域都視為新區域的新卡，原有效果不再適用（3.1.4）。

### 3.3 遊戲準備（第 5 章）

1. 出示卡組，只在這一刻檢查構築合法性（5.2.1.1）。
2. 洗牌，放到山札。
3. **隨機**決定先攻。不容許「勝方選擇先後攻」（5.2.1.3.1）。
4. 各抽 5 張。**由先攻玩家開始，各一次**，把任意張數手牌放到控え室，再抽相同張數（5.2.1.4）。
5. 先攻玩家開始回合。

注意：規則沒有「先攻第一回合不抽牌」的條文，所以先攻第一回合**照常抽牌**；唯一限制是**先攻第一回合只能攻擊一次**（7.2.1.3.1.2）。

### 3.4 回合結構（第 6 章）

| 階段 | 內容 |
|---|---|
| Stand | 觸發「回合開始時」→ Check Timing → 所有角色 Stand → Check Timing |
| Draw | 觸發 → Check Timing → 抽 1 張 → Check Timing |
| Clock | 觸發 → Check Timing → **可以**把 1 張手牌放到 Clock，這樣做就抽 2 張 → Check Timing |
| Main | 可重複進行：出角色（指定枠）、出 Event、使用起動能力、交換兩個枠的卡（6.5.1.2.4） |
| Climax | 最多出 1 張 Climax，之後不再獲得 Play Timing（6.6.1.2.2） |
| Attack | 見 3.5 |
| End | 觸發「回合結束時」→ 手牌超過上限要棄到上限 → Climax 放到控え室 → Check Timing →「回合結束前」的效果消失 → 若期間有任何處理發生，**整個 End Phase 重做**（6.8.1.5） |

### 3.5 攻擊（第 7 章）

每次攻擊是一個「アタックサブフェイズ」：

1. **アタック宣言ステップ**：選 1 個前列 Stand 角色，或選擇結束攻擊（直接進入 Encore Step）。
   - 正面沒有對手角色 → 自動成為 Direct Attack，該回合 Soul +1。
   - 正面有對手角色 → 選 Front 或 Side。Side Attack 時，Soul 減去正面角色的 Level。
   - 宣告後即使正面角色改變，攻擊方式及 Soul 增減**不變**（7.2.1.4.3）。
   - 之後才把攻擊角色 Rest。
2. **トリガーステップ**：山札頂 1 張表向放到解決領域 → 執行圖示效果 → 裏向放到 Stock。只執行該卡**放到解決領域當刻**擁有的圖示（7.3.1.2.2）；多個圖示可按任意順序執行。
3. **カウンターステップ**（只有 Front Attack）：對手只可使用帶 Counter 圖示的 Event 或角色起動能力，**只限一次**。
4. **ダメージステップ**：攻擊角色給予等於其 Soul 的傷害。Soul ≤ 0 時不給予傷害（並非「0 點傷害」）。
5. **バトルステップ**（只有 Front Attack）：比較 Power，較低一方 Reverse；相同則雙方 Reverse。
6. 觸發「攻擊結束時」→ 回到宣告步驟。

**アンコールステップ**：回合玩家逐張選擇自己的 Reverse 角色放到控え室，每張之後都有 Check Timing；之後輪到非回合玩家；直到場上沒有 Reverse 角色才進入 End Phase（7.7）。

### 3.6 傷害處理（4.12）— 最易出錯

1. 受傷玩家把山札頂 1 張表向移到**解決領域**。
2. 如果是 Climax：這次傷害中移到解決領域的**所有卡**放到控え室，傷害處理結束（Damage Cancel）。
3. 如果解決領域已有 N 張：全部**保持順序、同時**放到 Clock 最上（3.13.1.3.1）。否則回到 1。

- 不是由「給予傷害」造成的放 Clock（例如 Clock Phase、Refresh 懲罰、Cost）**不是傷害處理**，不會 Cancel（4.12.2）。
- 傷害期間翻出／移動的卡，不算作「被效果公開／移動的卡」，除非效果明確指明（4.12.3）。

### 3.7 Refresh（9.2）— 與舊資料不同

- 山札沒有卡時**即時中斷**目前行動（插入型規則處理）。
- 把控え室全部卡洗入山札，然後**立即**把山札頂 1 張放到 Clock（9.2.2）。
- **重要**：自 ver. 1.97（2022-08-01）起，懲罰是 Refresh 處理的一部分，洗牌後馬上執行。舊教材所說「先記下 Refresh Point，稍後才結算」的做法**已不是現行規則**。你需求中的「Refresh Point」會按 9.2.2 實作為即時懲罰。
- 傷害途中山札耗盡：中斷 → Refresh → 放 1 張到 Clock（此張不是傷害、不會 Cancel）→ 繼續餘下傷害。解決領域的卡不在控え室，所以不會被洗回山札。
- 山札耗盡而控え室也是 0 張時（9.2.2.1）：
  - 正在進行傷害處理，且解決領域沒有 Climax → **即時敗北**。
  - 否則 → 不執行 Refresh，直到再次出現「山札 0、控え室有卡」。
- **支付 Cost 期間不執行 Refresh 及 Level Up**（8.4.2.1、9.2.3、9.3.3），支付完成後才處理。
- ディスカバリー圖示執行期間，被公開的卡仍算在山札，執行期間不 Refresh（4.14.2.13.1）。

### 3.8 Level Up（9.3）

- Clock 有 7 張或以上時即時中斷（插入型）。
- 由**最下面 7 張**中選 1 張放到 Level 置場，其餘 6 張按自選順序放到控え室。第 8 張起留在 Clock。
- Level 4 的敗北在下一次 Check Timing 才判定。

### 3.9 Check Timing 與能力處理（4.4、8.5、8.7）

Check Timing 的固定程序（8.5.1）：

1. 同時執行所有待處理的規則處理；若因此產生新的規則處理，重複。
2. 回合玩家有待機的自動能力 → 選 1 個 Play 並解決 → **回到 1**。
3. 非回合玩家有待機的自動能力 → 選 1 個 Play 並解決 → **回到 1**。
4. 結束。

- 自動能力觸發幾次就待機幾次（8.7.2.1）。
- 待機的自動能力**必須** Play；玩家只可選擇自己多個能力的先後次序（8.7.3.1）。
- 帶「回合 N 次」限制的自動能力，可選擇不 Play 而取消一次待機（10.19.4）。
- 能力所屬的卡已換區域，仍然要 Play；只是無法執行的部分會失敗（8.7.7）。
- 每次獲得 Play Timing 之前必定先有 Check Timing（4.5.2）。

規則處理分兩類（9.1.2）：

| 類型 | 何時執行 | 包括 |
|---|---|---|
| 插入型 | 條件成立即時中斷 | Refresh、Level Up |
| 檢查型 | 只在 Check Timing | 敗北判定、Power ≤ 0 的角色放控え室、不合法卡處理、同一枠多張角色（只留最後放置的一張）、無主 Marker |

### 3.10 Play 與 Cost（8.4、8.6）

Play 的程序（8.6.2）：指定卡或能力 → 作出所需選擇（角色要選枠）→ 決定並支付全部 Cost →「已 Play」事件發生 → 解決。

- **顏色條件**：卡的顏色要與自己 Level 置場或 Clock 置場的任何一張卡相同。**Level 0 的角色和 Event 不需要**（8.6.2.1.1.1）。Climax 需要符合顏色。
- **Level 條件**：卡的 Level ≤ 自己 Level 置場的張數。Climax 不檢查 Level（8.6.2.1.2.1）。
- Cost 不能只付一部分；付不起就不能 Play（8.4.2.2）。
- 圓圈數字 = 由 Stock 最上面起，把該張數放到控え室（8.4.3、3.10.2）。
- 把角色出到已有角色的枠是容許的；原有角色會在下一次規則處理時放到控え室（8.6.2.5.1、9.6.2）。
- 「選 N 張」必須盡量選滿；「選最多 N 張」可選 0 張（8.6.3.1）。
- 從非公開區域按條件選卡時，可以聲稱沒有而不選（8.6.3.1.4）。

### 3.11 持續效果的套用次序（8.9）

1. 卡面印刷數值。
2. 不改變 Power／Soul 的持續效果。
3. 改變 Power／Soul 的持續效果。
4. 有依存關係時，被依存的先套用。
5. 其餘按發生時間先後。

非永續能力產生的持續效果，不會套用到之後才進入枠的卡（8.9.2）。

### 3.12 置換效果、最終資訊、循環（8.10、8.11、11.1）

- 同一事件有多個置換效果時，由受影響的玩家決定次序；每個置換效果對同一事件最多套用一次。
- 卡離開區域後，效果參照它最後在該區域時的資訊（最終資訊）。
- 永久循環：雙方都無法停止 → 平手；只有一方可停止 → 該玩家宣告重複次數；雙方都可停止 → 取較小的次數（11.1.1）。

## 4. 卡組構築規則（S-03、綜合規則 5.1）

- 剛好 50 張；同名卡最多 4 張（即使其他資料不同，同名就合計）；Climax 合計最多 8 張。
- 卡牌自身關於構築的永續能力會置換以上條件（5.1.2.4），例如「可放任意張數」的卡。
- **Neo-Standard**：選一個 Title，只用該 Title 的卡。Title 由卡號斜線前的部分決定，另有特例（例如 `Ssy/` 可與 `SY/` 一起使用）。
- 限制類型有四種，驗證器全部都要支援：
  - 使用不可（禁卡）
  - ○枚まで（張數限制）
  - ○種選抜（由指定組別中最多選 N 個卡名，其餘不可用）
  - 附帶特殊條件的解禁（例如 BanG Dream! 的ミッシェルシール，要全部角色都有指定特徵）
- 現時 Neo-Standard 有 28 個 Title 有限制項目；Standard／Side 限定另有 21 張及 23 張禁卡。
- 限制表會定期改定（下次公告預定在 12 月至 1 月初），所以限制資料必須是**帶生效日期的獨立資料檔**，不能寫死在程式內。

## 5. 官方卡表的技術結構（S-07）

- 單卡頁面：`https://ws-tcg.com/cardlist/?cardno=<卡號>`
- 卡圖：`https://ws-tcg.com/wordpress/wp-content/images/cardlist/<路徑>.png`（例：`s/sao_s20/sao_s20_001.png`）

- `robots.txt` 只禁止 `/wordpress/wp-admin/`。
- 網站頁尾**沒有**任何關於圖片或資料轉載的使用條款，只有各作品的 © 標示、私隱政策及聯絡表格。**沒有明示許可 ≠ 可以使用**，處理方法見 [../docs/03-phase1-plan.md](../docs/03-phase1-plan.md) 的版權部分。
