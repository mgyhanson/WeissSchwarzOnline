# 規則登記表（Rule Registry）

- 規則來源：日文《総合ルール》ver. 1.114（2026-11-10）
  https://ws-tcg.com/wordpress/wp-content/uploads/2026/11/10172953/WS_rule_1.114.pdf
- 構築規則來源：https://ws-tcg.com/rules/deck_rule/（2026-11-06）
- Rule ID 格式：`CR-<官方條文編號>`（Comprehensive Rules）、`DR-<序號>`（Deck Rules）。直接沿用官方編號，方便追溯。
- 「說明」欄是中文轉述，不是官方原文。
- 實作狀態：`未實作` → `部分`（只完成該條的一部分，備註見第 14 節）→ `已測試`（已實作並有通過的測試）。
- 測試案例欄是測試編號。已完成的測試在 `game-engine/tests/` 內，測試名稱以該編號或 Rule ID 開頭，可直接搜尋。

`rules/registry.json` 由這份表自動產生（`npm run registry`），請只編輯這份 Markdown。測試會自動檢查：標為「已測試」的規則都有測試名稱提及它的 Rule ID 或測試編號；標為「部分」的規則在第 14 節有說明；標為「未實作」的規則沒有測試聲稱覆蓋它；測試名稱中的測試編號都在這份表內。

## 14. 目前狀態的備註（截至 STEP 4d-2）

STEP 4d 分成幾部分完成。4d-1 是能力引擎的核心；4d-2 加入了較常見的關鍵字；其餘少見或複雜的內容列在下面「尚未實作」，會在匯入真實卡牌時按需要逐項加入。

### 已可用資料表達並由引擎執行的內容

能力的資料格式定義在 `game-engine/src/abilities/types.ts`，每個構件旁邊都寫明它對應的日文卡牌用語。

- **【永】**：對自己、(其他)自己的角色全部、自己前面的角色，增減 Power／Soul／Level；可帶條件；応援（只在後列有效）；Climax 的永續效果。
- **【自】**：觸發條件有「(由手牌)放到舞台時」「攻擊時」「Reverse 時」「戰鬥對手 Reverse 時」「某階段開始時（自己／對手／任何回合）」「自己的 Climax 放到 Climax 置場時」；可帶條件、可選 Cost、「可以」、回合次數限制。
- **【起】**：Main Phase 由舞台使用；Counter Step 由手牌使用（助太刀）。
- **Event** 的效果。
- **條件**：自己／對手的回合、Climax 置場有指定名稱的卡（CX Combo）、(其他)符合條件的角色達 N 張、玩家 Level、経験、記憶。
- **Cost**：Stock、Rest 自己、棄手牌、把這張卡放控え室、山札頂放 Clock。支付期間不 Refresh、不 Level Up。
- **效果**：抽牌、選卡、移動到各區域（可向對手展示、可 Rest 放置、可放到「這張卡原本的枠」）、該回合增減數值、Stand／Rest／Reverse、給予傷害、山札頂放到指定區域、洗牌、集中、條件分支。
- **STEP 6 新增**（為兩副 Trial Deck 而加）：條件「這張卡在指定的枠」「這張卡處於 Rest」「我方所有角色都是…」「Stock N 張以下」；Cost「把這張卡放到 Clock」；選對手前列角色、選對手的 Climax；選我方的枠（任意或後列空枠）；Clock 最上面 1 張放控え室；查看山札頂最多 N 張並取 1 張（可向對手展示，N 可按角色張數計算）；給予自動能力（該回合，或由永續能力持續給予）；Power 按目標的 Level 計算；觸發「手牌或 Change 放到舞台時」「這張 Climax 由手牌放到 Climax 置場時」「我方 Trigger Check 翻出指定的卡時」「使用了這張卡的助太刀時」；集中翻開的卡的張數作為 X。
- **4d-2 新增**：絆；Encore 的其他 Cost；チェンジ；大活躍；アラーム（在 Clock 最上面時生效的永續及自動能力）；「…ステップ開始時」的觸發；「舞台から控え室に置かれた時」的觸發；「…1 枚につき」按張數計算的數值。
- **STEP 6b 新增**（為 SAO/S20 及 GUP/W141 而加）：觸發「我方 Trigger 圖示是某種的 Climax 放到 Climax 置場時」（`CLIMAX_PLACED` 加卡牌條件）；條件「Climax 置場有任何 Climax」（`CLIMAX_IN_PLAY` 不指定名稱）。Shot、Draw、Treasure、Choice、Gate 五種 Trigger 圖示已由真實卡牌的提示文字核實，並以真實卡牌測試。
