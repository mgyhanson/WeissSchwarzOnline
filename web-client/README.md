# web-client：瀏覽器介面

非官方的社群專案，與 Bushiroad 及各作品的權利人無關。

## 啟動

在專案根目錄：

```bash
npm run dev       # http://localhost:5173
npm run dev:lan   # 同一 Wi-Fi 的手機也可以連接
npm run build     # 正式版，輸出到 web-client/dist.nosync/（iCloud 不同步）
```

## 結構

| 位置 | 內容 |
|---|---|
| `src/host/local.ts` | `GameHost` 介面及 `LocalHost`：在瀏覽器內執行引擎。介面只取得自己座位的玩家視圖及已過濾的事件。對局以種子加答案列表保存在 localStorage |
| `src/bot/practice.ts` | 練習對手：只按簡單規則行動，只看自己座位的玩家視圖。**不是** STEP 8 的正式 AI |
| `src/model/options.ts` | 把引擎的 `Decision` 轉成按鈕、卡牌行動及選卡。所有選項都由合法答案產生 |
| `src/model/cards.ts` | 卡牌顯示資料：官方資料、官方文字、中文說明及其來源標示、官方卡表連結 |
| `src/model/log.ts` | 對局紀錄的中文文字，只用已過濾的事件 |
| `src/model/glossary.ts` | 術語解釋（本專案自行撰寫，附綜合規則條號） |
| `src/model/text.ts` | 各種引擎數值的中文名稱 |
| `src/components/` | React 元件：棋盤、卡牌、決定面板、卡牌詳情、主頁、卡牌一覽、術語頁 |

## 原則

- 介面不判斷規則。可以做的事全部來自引擎列出的合法答案。
- 介面及練習對手都只看到自己座位可以看到的資訊。
- 不使用官方卡圖：卡牌以資料繪製，並附官方卡表連結。
- 中文說明一律標示來源及核實狀態（目前全部是「AI 輔助說明（非官方）・待核實」）。

## 測試

`tests/client.test.ts`（在根目錄執行 `npm test`）：

- 以「只按介面提供的選項」隨機打 24 局完整對局（四種卡組配對，雙方座位輪流），每個決定都檢查：介面提供的每個選項都是合法答案；引擎列出的每個合法答案都有提供；選卡的張數範圍與決定相同；每張要顯示的卡都能從玩家視圖辨認。
- 練習對手互相對戰 8 局，全部分出勝負。
- 對局紀錄沒有缺漏的數值；看不到的移動不會寫出卡名。
- 每張卡都可以顯示，中文說明有來源標示；能力文字與能力資料逐條對應。
- `LocalHost`：只提供自己座位的視圖；自動代打可以打完整局；不是自己的決定時忽略提交；投降；保存後重新載入回到完全相同的局面；損壞的保存資料不會被載入。

測試曾以故意改壞程式驗證：拿走交換位置、Clock 張數上限寫錯、拿走「結束攻擊」、拿走助太刀、查看山札時不顯示卡，五種錯誤都會令測試失敗。

## 已知限制

- 練習對手很弱，例如每次被正面攻擊都會用助太刀。
- 動畫只有簡單過渡；對方的行動要看對局紀錄。
- 沒有拖放操作，一律點擊卡牌再選行動。
