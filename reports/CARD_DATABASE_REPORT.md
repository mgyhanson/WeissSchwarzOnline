## 資料架構

- 官方資料：`card-database/sets/<系列>/official.json`（原樣儲存，可由匯入工具重新產生）。
- 人手能力資料及中文解釋：`sets/<系列>/cards.ts`。
- 句式：`src/patterns.ts`。賽制及限制表：`src/formats.ts`。
- 圖片：與資料分離，只在 `card-assets/local.nosync/`（見 `CARD_IMAGE_REPORT.md`）。
- 匯入設定：`card-database/import/sets.json`；匯入報告：`reports/card_import_report.{json,md}`。

## 匯入工具（可重複執行）

```bash
npm run cards:import
```

- 每秒不多於一個請求（1.1 秒間隔）；官方網站的 robots.txt 容許這些路徑。
- 所有原始回應保存在 `data.nosync/import-cache/`，再次執行時不會重新下載（`--refresh` 才會）。
- 以卡號為主鍵，不會產生重複卡；已有的圖片不會被覆蓋；出錯會重試三次，仍然失敗則記入報告並繼續。
- 會比對上次匯入的資料，官方資料有改變時在報告列出。
- 這次共 1081 個請求，缺少資料 0，失敗 0。
