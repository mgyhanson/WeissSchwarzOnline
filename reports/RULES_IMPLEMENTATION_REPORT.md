## 已支援的卡牌效果（每種都有測試）

- **能力種類**：永續（【永】）、自動（【自】）、起動（【起】），包括 Counter 時機的助太刀；Event 效果。
- **觸發**：放到舞台（手牌／Change）、攻擊時、Reverse 時（包括「戰鬥中」）、戰鬥對手 Reverse 時、各階段及攻擊各步驟開始時、Climax 放置時、Trigger Check 翻出指定的卡時、使用助太刀時、由舞台放到控え室時。
- **Cost**：Stock、Rest 自己、Rest 其他角色、棄手牌、這張卡放控え室／Clock／思い出、山札頂放 Clock、Stock 放 Clock。
- **效果**：抽牌、選卡、搜尋山札、回收（Salvage）、移動到各區域、Stock 操作、Clock 操作、思い出、Power／Soul／Level 增減（該回合、或直到下一個對手回合結束）、Stand／Rest／Reverse、傷害、洗牌、集中、查看山札頂、給予能力、條件分支。
- **關鍵字**：応援、助太刀、集中、絆、チェンジ、大活躍、アラーム、経験、記憶、加速、Encore、CX Combo。
- **Trigger 圖示**：13 種全部有引擎測試；其中 9 種已由真實卡牌的提示文字核實圖示圖片（這次新增 Standby）。
- **結算次序**：Check Timing、同時待機的能力由玩家選次序、Cost 不能支付時不提供、無效目標、傷害途中 Refresh／Level Up、Damage Cancel、勝負判定。

## 尚未支援（如實列出）

登記表第 14 節的清單，主要有：一般置換效果、シフト、Marker 類關鍵字（回想、搭乗、合体等）、在思い出／控え室／手牌生效的能力、狀態觸發、其他卡移動引發的觸發、「攻擊結束時」、影響對手角色的永續效果、「不能被對手的效果選擇」、「不能側面攻擊」、手牌中改變 Level、多次 Trigger Check、按對手角色數目計算的數值等。

這五個新補充包大量使用以上內容（例如 NIKKE 的「回想」、GUP 的 Marker），這就是它們大部分卡未支援的原因。

## 2026-11-14：為 BDY/W135 第一批加入的通用構件

全部是通用的資料構件（`game-engine/src/abilities/types.ts`），引擎內沒有任何按卡號判斷的程式碼。每一項在 `game-engine/tests/abilities-batch-3.test.ts` 以合成測試卡測試（15 項），並在 `card-database/tests/cards-bdy.test.ts` 以真實卡牌測試（14 項）。

| 構件 | 對應的卡牌用語 | 種類 |
|---|---|---|
| `HAND_TO_CLOCK` | ［手札を1枚クロック置場に置く］ | Cost |
| `SELF_TO_DECK_BOTTOM` | ［このカードを山札の下に置く］ | Cost |
| `names` | 「A」か「B」 | 卡牌條件 |
| `levelAboveMasterLevel` | レベルが相手のレベルより高いキャラ | 卡牌條件 |
| `BATTLE_OPPONENT` | このカードのバトル相手の…が…なら | 條件 |
| `FACING` | このカードの正面のキャラの…が…なら | 條件 |
| `YOUR_SLOT` | (他の)あなたの前列の中央の枠のキャラ | 對象 |
| `OPPONENT_BACK_ROW`、`CHOOSE` 的 `add` | 相手の前列の…を1枚までと相手の後列の…を1枚まで選び | 選擇 |
| `WAITING_ROOM_TO_DECK` | 自分の控え室のカードすべてを、山札に戻し | 效果 |
| `OTHER_ATTACKS` | 他のあなたの…のキャラがアタックした時 | 觸發 |

測試的可信程度：在引擎內故意植入 19 個錯誤（例如把放到 Clock 改成放到控え室、忽略卡名條件、把「高於」改成「不低於」、觸發時包括自己或對手的攻擊），測試全部能發現。其中一個原本多餘的檢查（戰鬥對手是否仍在舞台）因為規則 CR-3.1.4（卡離開區域後是新的卡）已保證而移除。
