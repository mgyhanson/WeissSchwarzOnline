# ANIMATION_REPORT — 戰鬥動畫、階段解說及戰鬥紀錄

2026-11-14。

## 架構：動畫與規則分離

```
規則引擎（遊戲狀態）→ 事件（按座位過濾）→ 步驟（steps.ts）→ 播放佇列（queue.ts）→ 畫面
```

- 所有數值及卡牌位置只由規則引擎決定。播放佇列只決定**甚麼時候顯示**，不能改變遊戲狀態。
- 播放期間棋盤保持更新前的狀態，播完才換成新狀態，所以畫面不會與引擎不一致。
- 播放期間不會出現決定按鈕；每個決定有唯一編號，引擎（及網上對戰的伺服器）只接受目前待決定的那一個答案。重複點擊不會造成重複攻擊、重複抽牌或效果觸發兩次（有測試）。
- 暫停、逐步、跳過只控制畫面。網上對戰時對手不會被你的暫停拖住規則處理。

## 動畫速度

四級：慢速（×1.7）、正常（預設）、快速（×0.35）、關閉。另有暫停及逐步播放。

| 動作 | 升級前 | 現在（正常速度） |
|---|---|---|
| 一般卡牌移動 | 280 ms | 700 ms |
| 自己抽牌 | 650 ms＋每張 120 ms | 800 ms＋每張 300 ms |
| Rest／Stand | 220 ms | 500 ms（Reverse 900 ms） |
| 攻擊宣言 | 700 ms | 1100 ms |
| Trigger Check | 900＋700 ms | 1100＋1000 ms |
| 傷害判定 | 每張 550 ms，結果 900 ms | 逐張 700 ms，結果 1200 ms |
| 能力發動 | 800 ms | 1300 ms |
| 階段轉換 | 200 ms | 700 ms |
| 攻擊的各步驟 | 沒有顯示 | 600 ms |
| Level Up／Refresh | 1100 ms | 1400 ms |

不同動作的時間不同；慢速時全部再乘 1.7。

## 每個階段的提示

- 階段開始時播放「你的／對手的 ○○ 階段」及該階段的用途、系統會做甚麼。
- 決定面板下方有可展開的「這個階段可以做甚麼？」：用途、你可以做的事、系統會做的事、下一步的條件，並附綜合規則條號。
- 上方的階段標示及階段列會跟隨正在解說的階段。
- 遊戲的階段按官方規則是七個：Stand、抽牌、Clock、主要、Climax、攻擊、結束。**Encore 在官方規則中是攻擊階段的最後一個步驟（CR-7.7），不是獨立的階段**；它以「Encore 步驟」顯示及解說。

## 攻擊流程逐步呈現

每一步都有獨立的動畫及文字：

1. 攻擊宣言步驟：誰的哪一格角色攻擊、攻擊方式（正面／側面／直接）及其意思、目標角色；攻擊角色轉為 Rest。
2. Trigger 步驟：翻開的卡、Trigger 圖示及它的效果；沒有圖示也會說明；之後放到 Stock。
3. Counter 步驟（只限正面攻擊）。
4. 傷害步驟：逐張翻開；說明受到多少點、是否翻到 Climax 而 Cancel（指出是哪一張）、或全部放到 Clock。
5. 戰鬥步驟：哪個角色被 Reverse 及原因。
6. Encore 步驟：Reverse 的角色放到控え室，或支付費用留場。
7. 能力發動時顯示是哪張卡的能力及官方原文，可以按「查看這張卡」。

## 戰鬥解說紀錄（Battle Event Log）

右方（手機按「紀錄」）的「戰鬥解說紀錄」：每個重要步驟一項，包括標題、回合、時間、涉及的玩家（以顏色區分）；按一下展開完整解說及涉及的卡，可以點卡查看卡牌詳情。最多保留 400 項。跳過動畫時，被跳過的步驟仍然按次序記入紀錄。

下方另有「詳細事件紀錄」（引擎事件逐條列出）及「已揭示的卡」（可以再次查看翻開過的卡）。

只顯示你這個座位可以看到的資訊：對手抽到的卡不會出現在解說或紀錄中（有測試）。

## 控制

播放期間決定面板顯示解說及：「⏸ 暫停／▶ 繼續」、「逐步播放」（每一步等你按「下一步 ▶」）、「跳過動畫」。速度可隨時在上方更改。

## 測試

- 暫停時不播放、繼續後由原位置播完；逐步模式每按一次只播一步，連按兩次不會跳步；跳過會結束等待並顯示最新局面；紀錄次序正確。
- 戰鬥紀錄包含攻擊、Trigger Check、傷害（Cancel 或沒有取消）；對手的抽牌不含卡名。
- 瀏覽器（Playwright）：電腦及手機都出現階段解說；逐步模式確實停住，按「下一步」後前進；三種畫面尺寸都是 60 fps；沒有橫向捲動；沒有頁面錯誤。

## 已知限制

- 「重播重要事件」目前是在紀錄中重新展開解說及查看涉及的卡，不會重新播放該段動畫。整局的重播在「重播」頁面。
- 一次更新之內棋盤在播完後才換成新狀態，過程由飛行的卡、揭示面板及解說呈現。
- 沒有音效。
